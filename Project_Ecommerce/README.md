# Vessel Storefront

A prototype full‑stack storefront application built as part of my internship tasks.  
This project demonstrates a modern e‑commerce front‑end with modular sections, interactive UI, and backend integration potential.

---

## ✨ Features

- **Responsive Header & Navigation**
  - Logo, navigation links, login, cart, and hamburger menu for mobile.
- **Hero Section**
  - Marketing copy with call‑to‑action buttons.
  - Featured product card with image, title, and price.
- **Shop Section**
  - Dynamic product grid populated via JavaScript.
  - Filter row for catalog browsing.
- **About Section**
  - Brand philosophy with glass‑style cards.
- **Footer**
  - Multi‑column layout with shop, studio, and support links.
  - Attribution and prototype disclaimer.
- **Interactive Modals**
  - Cart drawer with subtotal and checkout.
  - Product detail modal.
  - Authentication modal.
  - Orders modal.
  - Toast notifications.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (glassmorphism styles), JavaScript (for interactivity)
- **Backend (planned):** Node.js / Express (for authentication, orders, checkout)
- **Database (planned):** MongoDB or PostgreSQL
- **Version Control:** Git & GitHub
